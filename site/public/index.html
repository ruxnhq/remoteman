remoteman

See and control your own computers from your other devices, directly and encrypted end to end. No accounts, no servers in between.

Version 0.1.0. On the computer you want to reach, install the host. On the device you reach it from, install the viewer.

Windows

Windows 11, x64. The installers aren't code-signed yet: if Windows says it protected your PC, choose More info, then Run anyway.

  • Hostremoteman-host-setup-0.1.0.exe20.7 MBSHA-256
  • Viewerremoteman-viewer-setup-0.1.0.exe48.7 MBSHA-256
  • Viewer, no installremoteman-viewer-windows-0.1.0.zip67.7 MBSHA-256

Mac

Apple silicon. Signed and notarized by Apple. Open the disk image and drag the app to Applications.

  • Hostremoteman-host-0.1.0-macos.dmg2.3 MBSHA-256
  • Viewerremoteman-viewer-0.1.0-macos.dmg2.5 MBSHA-256

Linux

GNOME on x86_64, with GTK 4.20 and libadwaita 1.6 or newer. Make the AppImage executable, then open it.

  • Hostremoteman-host-0.1.0-gnome-x86_64.AppImage18.0 MBSHA-256
  • Viewerremoteman-viewer-0.1.0-gnome-x86_64.AppImage10.3 MBSHA-256
